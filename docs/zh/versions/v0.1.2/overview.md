# v0.1.2 概览

v0.1.2 在 v0.1.1 的 `lime-novel` 实现抽象基础上，加入 `Novel Harness Engine / 小说驾驭引擎`。

重点新增：

- 小说驾驭引擎概念。
- Story / Character / Reader 三层 Harness。
- 发布前 `sandbox` 沙盘模式。
- 发布后 `timeline` 时间线模式。
- 小说体检报告。
- 黄金三章专项评估。
- 冲击波分析。
- 读者反馈映射与回潮声明。
- Harness 相关 JSON Schema。
