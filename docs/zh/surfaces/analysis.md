# 拆书工作面

拆书工作面用于写前建模，不用于复制样本文本。它给 Reader Harness 提供参照：目标读者为什么被吸引、在哪里停留、为什么弃读。

## 核心指标

- hookStrength：开头钩子。
- characterHeat：人物吸引力。
- pacingMomentum：节奏动能。
- feedbackResonance：读者反馈共振。
- goldenThreeSurvival：黄金三章生存率。
- expectationControl：读者预期控制。

## 拆书对象

- 爆点拆解。
- 人物吸引力观察。
- 节奏结构观察。
- 读者反馈。
- 黄金三章结构。
- 伏笔和回收节奏。
- 对本项目的启发。

## Harness 输出

拆书代理不输出“照抄建议”，只输出可迁移的结构洞察：

| 输出 | 用途 |
| --- | --- |
| reader pattern | 目标读者对钩子、爽点、关系、反转的响应模式。 |
| pacing reference | 同类作品的高潮间距、说明密度、转场方式。 |
| golden-three note | 开局三章的钩子、主角共鸣、世界沉浸参照。 |
| risk hint | 当前项目可能踩到的节奏、设定或期待风险。 |

拆书结果进入 analysis artifact、compiled report 或 outputs，不直接成为正文。
