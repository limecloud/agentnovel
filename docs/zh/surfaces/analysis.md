# 拆书工作面

拆书工作面用于写前建模，不用于复制样本文本。

## 核心指标

- hookStrength：开头钩子。
- characterHeat：人物吸引力。
- pacingMomentum：节奏动能。
- feedbackResonance：读者反馈共振。

## 输出

- 爆点拆解。
- 人物吸引力观察。
- 节奏结构观察。
- 读者反馈。
- 风险提醒。
- 对本项目的启发。

拆书结果进入 analysis artifact、compiled report 或 outputs，不直接成为正文。
