# 发布工作面

发布工作面负责把作品资产转成可交付产物。

## 能力

- Markdown 导出。
- EPUB 导出。
- 平台简介草案。
- 发布备注草案。
- 版本比较。
- 资产检查。
- 最终确认。

## 导出结果

每次导出生成目录和 `manifest.json`，记录 preset、version、synopsis、splitChapters、notes、feedback 和 files。

## 审批

最终导出需要作者确认。外部发布或同步必须走更严格策略。
