# 设定工作面

设定工作面是项目长期一致性的前台，不是后台管理页。它同时服务 canon 和 Harness：canon 记录事实，Harness 驾驭这些事实如何影响剧情推进。

## 视图

- 卡片视图。
- 关系图。
- 时间线。
- 人物状态机。
- 伏笔链。
- 信息差矩阵。

## 卡片状态

- candidate：候选事实。
- confirmed：已确认事实。
- archived：废弃或历史事实。

## Harness 对象

| 对象 | 说明 |
| --- | --- |
| 人物状态机 | 按章节记录目标、信念、关系、能力、创伤、转折。 |
| 伏笔链 | 记录种下点、强化点、误导点、回收点和过期风险。 |
| 时间线 | 记录事件顺序、因果、角色到场能力和已发布不可逆边界。 |
| 信息差矩阵 | 区分作者知道、角色知道、读者知道。 |

## 设定代理

设定代理负责提取候选、发现冲突、同步人物状态、生成时间线事件。候选不能自动升级为 confirmed，除非策略允许或作者确认。

在 `timeline` 模式下，设定代理还必须标记 retcon 风险：任何与已发布事实冲突的设定修改，都应转为 future fix 或回潮声明，而不是静默覆盖历史。
