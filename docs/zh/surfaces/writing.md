# 写作工作面

写作工作面是 Agent Novel 的主战场。正文编辑器在中央，Agent 侧栏只辅助，不抢焦点。

## 结构列

- 章节树。
- 场景列表。
- 当前章节目标。
- 本章状态。

## 主工作面

- 正文编辑器。
- 选区操作。
- 行内提议。
- 提议接受/拒绝。
- 差异对照。

## 章节代理

章节代理可以：

- 基于当前章节目标续写。
- 改写选区。
- 补强场景目标。
- 根据 canon 和 compiled memory 控制连续性。
- 保存 proposal，不直接覆盖正文。

## 编辑器协议

Tiptap 或其他编辑器只是 UI 状态源；保存后才通过应用层回写章节文件。右栏消息变化不应导致编辑器实例重建。
