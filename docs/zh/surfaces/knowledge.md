# 知识工作面

知识工作面承接小说长期记忆，不是通用第二大脑。

## 能力

- 导入 `.txt` / `.md` / `.markdown`。
- 展示 raw、compiled、canon、outputs。
- 针对项目问题生成 brief/report。
- 写入 `outputs/answers/`。
- 把稳定事实推荐回 canon。

## 健康度

知识工作面 SHOULD 展示：

- 知识资产数量。
- 最近输出。
- 当前范围。
- 过期、冲突、未来源化问题。

## 问答原则

回答必须区分已知、推断和未知。资料缺失时应说明缺口，不编造。
