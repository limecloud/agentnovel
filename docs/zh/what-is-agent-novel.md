# 什么是 Agent Novel？

Agent Novel 定义一种面向 AI Agent 的长篇小说工作台标准。它关注的不是“如何写一句更好的提示词”，而是一个长篇项目如何被保存、理解、修订、发布、审计和持续协作。

适用场景：

- 长篇小说、系列小说和共享宇宙创作。
- 需要章节推进、设定沉淀、连续性检查和发布整理的写作产品。
- 本地优先、文件可迁移、Agent 可读写的创作工具。
- 希望把 AI 结果从聊天气泡升级为可审批、可回写资产的系统。

不适用场景：

- 单次短文生成。
- 只有 prompt 模板、没有项目资产模型的写作助手。
- 把 Agent 运行时、技能脚本或模型 provider 直接塞进作品目录的系统。

## 核心判断

Agent Novel 的核心判断是：长篇小说是长期演进的作品系统，不是一次模型调用。

因此标准必须把下面对象分开：

| 对象 | 角色 |
| --- | --- |
| 正文 | 作者最终接受的章节与场景内容。 |
| 设定 | 角色、地点、组织、规则、时间线等连续性事实。 |
| 参考 | 外部素材、拆书样本、研究资料和导入文档。 |
| 修订 | 问题、提议、差异、应用记录和撤销记录。 |
| 发布 | Markdown、EPUB、包清单和导出诊断。 |
| 代理任务 | 后台工作单元，不等于作品事实。 |
| 证据 | 支撑建议、诊断和回写的来源片段。 |

## 与 Agent Skills 和 Agent Knowledge 的边界

| 内容 | 正确位置 | 原因 |
| --- | --- | --- |
| 如何拆书、如何续写、如何做连续性检查 | Agent Skills | 这是流程和能力。 |
| 拆书后的样本摘要、研究事实、风格观察 | Agent Knowledge 或 Novel references | 这是可引用知识。 |
| 小说项目目录、章节正文、设定卡和修订记录 | Agent Novel | 这是作品工作台协议。 |
| 工具调用、队列、错误、恢复和事件流 | Agent Runtime | 这是执行事实。 |
| 任务卡、证据卡、提议块和差异预览 | Agent UI | 这是可见交互投影。 |

## 运行时原则

兼容实现 SHOULD：

1. 优先读取项目文件而不是聊天历史。
2. 在模型调用前组装最小必要上下文。
3. 把 AI 输出保存为提议，而不是直接覆盖正文或设定。
4. 为有风险写入提供证据、差异和人工确认。
5. 保持索引、缓存和 embedding 可重建。
6. 让作者随时能备份、迁移和审查自己的作品资产。
