# 术语表

| 术语 | 含义 |
| --- | --- |
| Project package | 一个可迁移的小说项目目录。 |
| Manuscript | 作者已接受的正文事实源。 |
| Canon | 维护后的 story bible。 |
| Reference | 参考来源，不自动成为作品事实。 |
| Proposal | AI 或工具生成的可审查变更建议。 |
| Revision issue | 已记录的修订问题。 |
| Applied record | proposal 被应用后的审计记录。 |
| Evidence ref | 支撑 claim、issue 或 proposal 的来源引用。 |
| Context assembly | 为模型调用选择、压缩和注入上下文的过程。 |
| Runtime event | 执行事实，不等于作品事实。 |
