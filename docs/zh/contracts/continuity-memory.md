# 连续性与记忆契约

长篇小说最大的风险不是写不出下一段，而是写着写着忘了之前承诺过什么。Agent Novel 因此把记忆视为一等对象。

## 三层记忆

| 层 | 内容 | 生命周期 | 典型存储 |
| --- | --- | --- | --- |
| 工作记忆 | 当前章节、选区、当前任务、最近工具结果。 | 单任务/短会话 | runtime context / task snapshot |
| 章节记忆 | 本章目标、场景摘要、人物状态变化、伏笔状态。 | 单章/相邻章节 | `compiled/chapters/`、chapter summary |
| 项目记忆 | 世界规则、角色长期画像、跨章时间线、主题边界。 | 全书/系列 | `canon/`、`compiled/entities/`、`compiled/timelines/` |

## 连续性事实

连续性事实至少包括：

- 人物状态：知道什么、相信什么、误判什么、受伤/失去/获得什么。
- 关系状态：信任、敌意、隐瞒、债务、承诺。
- 物品状态：钥匙在谁手里、是否损坏、是否被使用。
- 地点状态：门是否开过、房间是否被发现。
- 规则状态：魔法/科技/社会规则是否已揭示。
- 信息差：读者知道但角色不知道，角色知道但读者不知道。
- 伏笔：埋设、强化、回收、废弃。

## 压缩

轻压缩用于工具结果、搜索结果和长引用；重压缩用于会话或项目上下文过大时。

压缩摘要 MUST 保留：

1. 已确认事实。
2. 候选事实。
3. 冲突和未决问题。
4. 来源引用。
5. 影响范围。
6. 不能提前泄露的信息。

## 缺失上下文

当上下文不足时，代理必须产生 missing-context 诊断，而不是编造。

示例：

```json
{
  "kind": "missing-context",
  "target": "chapter-13",
  "detail": "缺少第 12 章修订后的正式摘要，无法判断反派视角是否提前泄密。",
  "suggestedAction": "先读取第 12 章正文或生成章节摘要。"
}
```
