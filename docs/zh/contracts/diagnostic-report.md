# 小说体检报告

小说体检报告是 Harness 的诊断产物。它把“感觉哪里不对”转成可定位、可排序、可修复的问题清单。

## 1. 报告范围

报告可以覆盖：

- 单章。
- 连续章节段。
- 单卷。
- 全书。
- 黄金三章。
- 某条人物弧光。
- 某条伏笔链。
- 某个发布版本。

## 2. 诊断维度

| 维度 | 检查问题 |
| --- | --- |
| 结构 | 主线、卷册目标、章节功能是否一致。 |
| 节奏 | 冲突密度、信息释放、情绪高低、长平段。 |
| 人物 | 目标、信念、关系、能力、创伤、转折是否有因果。 |
| 伏笔 | 是否无根、断裂、过期、可回收或重复。 |
| 信息差 | 作者知道、角色知道、读者知道是否被清晰区分。 |
| 连续性 | 时间线、地点、设定、物件、能力规则是否冲突。 |
| 世界观负载 | 设定解释是否压垮场景推进。 |
| 读者风险 | 弃读点、误读点、期待落空点。 |

## 3. 黄金三章专项评估

黄金三章用于评估连载生存率，不等于机械套路。

| 指标 | 合格信号 |
| --- | --- |
| 钩子质量 | 开篇问题具体、有压力、有延展空间。 |
| 主角共鸣 | 主角欲望、困境、能力或缺陷能被读者抓住。 |
| 世界沉浸 | 世界规则进入冲突，而不是堆设定说明。 |
| 继续阅读动机 | 第三章结束时读者明确想知道下一步。 |

输出必须指出问题落点，例如“第 2 章 3 个连续说明段稀释了追击压力”，而不是“节奏略慢”。

## 4. Finding 结构

每个 finding 至少包含：

- `findingId`。
- `area`：结构、节奏、人物、伏笔、信息差、连续性等。
- `severity`：low、medium、high、blocking。
- `targetRefs`：章节、场景、角色、设定或导出版本。
- `evidence`：证据片段或摘要。
- `diagnosis`：问题判断。
- `recommendation`：下一步动作。
- `harnessLayer`：Story、Character 或 Reader。

## 5. 报告出口

体检报告可以产生：

- revision issue。
- intent plan。
- impact analysis。
- canon candidate。
- timeline iteration。
- publish blocker。

报告本身不直接改正文。
