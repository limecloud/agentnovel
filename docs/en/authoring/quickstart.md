# Author quickstart

Create `novel.json`, place accepted chapters under `manuscript/chapters/`, maintain story bible cards under `canon/`, keep imported source material in `references/`, store AI suggestions as `revisions/proposals/`, and write accepted changes only after user or policy approval.

A minimal agent-ready implementation can load a project, load the current chapter, search workspace assets, save proposals, save revision issues, show approval requests and apply approved proposals.
