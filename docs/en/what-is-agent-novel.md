# What is Agent Novel?

Agent Novel defines a portable workspace and Novel Harness contract for long-form fiction products. It is not a prompt template and not a chat transcript format. It describes how manuscripts, story bible facts, references, revisions, exports, agent tasks, evidence, approvals, diagnostics, impact analyses and reader feedback mappings stay separate and auditable.

Use it when a product needs chapter writing, canon extraction, continuity review, sandbox diagnostics, timeline repair, publishing preparation and explicit user-approved writeback.

Do not use it to store executable workflows, provider APIs or full runtime event protocols. Those belong to Agent Skills, Agent Runtime and adjacent standards.
