# Novel workspace

Agent Novel uses two centers:

- The work center owns author assets: chapters, canon, references, revisions and exports.
- The agent center owns active work: task selection, context assembly, tools, proposals, evidence and approvals.

Chat text is not a durable novel model. Long-form fiction needs explicit continuity, canon and revision structures.
