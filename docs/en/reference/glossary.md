# Glossary

| Term | Meaning |
| --- | --- |
| Project package | A portable novel project directory. |
| Manuscript | Accepted story text. |
| Canon | Maintained story bible facts. |
| Reference | Source material that is not automatically canon. |
| Proposal | Inspectable change suggestion. |
| Evidence ref | Source reference supporting a claim or proposal. |
| Runtime event | Execution fact, not project fact. |
