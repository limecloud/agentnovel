# Agent standards ecosystem

Agent Novel owns fiction workspace contracts. It interoperates with:

- [Agent Skills](https://agentskills.io/) for executable workflows.
- [Agent Knowledge](https://limecloud.github.io/agentknowledge/) for source-grounded knowledge packs.
- [Agent Runtime](https://limecloud.github.io/agentruntime/) for execution facts and control planes.
- [Agent UI](https://limecloud.github.io/agentui/) for visible surfaces and controls.
- [Agent Evidence](https://limecloud.github.io/agentevidence/) for provenance and review.
- [Agent Policy](https://limecloud.github.io/agentpolicy/) for permissions and approvals.
- [Agent Artifact](https://limecloud.github.io/agentartifact/) for durable deliverables.
- [Agent Tool](https://limecloud.github.io/agenttool/) for tool declarations and invocation facts.
- [Agent Context](https://limecloud.github.io/agentcontext/) for context selection and injection.
