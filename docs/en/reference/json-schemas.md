# JSON Schemas

Reference schemas are available under `/schemas/`. v0.1.2 adds schemas for the real Lime Novel workspace shell, agent feed items, submitted task results, knowledge documents, analysis samples and revision records.


v0.1.2 adds Harness schemas for `harness-profile`, `diagnostic-report`, `impact-analysis`, `intent-plan`, `reader-feedback` and `timeline-iteration`.
