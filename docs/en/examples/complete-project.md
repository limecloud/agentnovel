# Complete project example

A minimal project contains `novel.json`, one chapter under `manuscript/chapters/`, at least one canon card, source material under `references/`, revision issues and proposals under `revisions/`, exports under `exports/` and runtime support under `.lime/`.

AI output should first be stored as a proposal, displayed with evidence and diff, then applied after user approval.
