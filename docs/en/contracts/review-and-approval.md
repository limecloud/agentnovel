# Review and approval

Agent Novel defaults to proposal-first writeback. AI output should be inspectable before it becomes project fact.

A proposal should include a stable id, task id, target refs, summary, risk level, readable diff, evidence refs and status. Approval UI should show operation type, affected paths, risk, diff summary, evidence, reversibility and explicit accept/reject/defer actions.
