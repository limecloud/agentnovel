# Runtime events

Recommended event families include `novel.context.selected`, `novel.context.missing`, `novel.proposal.created`, `novel.evidence.linked`, `novel.approval.required`, `novel.asset.updated`, `novel.export.created` and `novel.issue.detected`.

Events are execution facts. Manuscript, canon, revisions and exports remain project facts.
